# Hindsight reviewer

Reviews injected and tool-recalled memories after an eligible gateway turn. The proposal, independent confirmation, exact evidence, fresh primary-fact read, reversible invalidation and readback gates remain unchanged. A newer admitted message cancels unfinished writes.

## Desktop delivery

Version 0.13.0 admits native Desktop turns only when the current local policy says Desktop and the active profile authority retains exactly one unfinished agent for the bound session, route and chat. Cron, Kanban, delegated, one-shot and non-Desktop local contexts stay idle. The captured agent background-review callback uses the native `review.summary` contract after reply completion. It never opens another turn, uses a local adapter send or redirects the notice to Telegram. Telegram private chats retain their existing sender; group notices remain suppressed.

The small Desktop resolver is copied verbatim into Jot reviewer so both plugins remain independently installable. Tests enforce copy equality and use the real turn sender, session events, registered hooks and isolated persistence. No scenario mutates a real memory bank.
